# 六套组合策略

在「性能与散热 → 功耗／风扇」分别选择静音／均衡／性能，以及插电／离电，得到六套独立配置。两个分区共用同一编辑对象和草稿。三种运行方式分别对应固件 `quiet`、`balanced`、`performance`，与「概览」命名一致。

1. 选择要编辑的组合。选择编辑对象不切换硬件状态。
2. 勾选要管理的功耗项并输入瓦数。范围和步长来自固件，在应用时重新检查。
3. 如需管理风扇，在「风扇」分区点击「读取方案曲线」，勾选「管理风扇曲线」，编辑各风扇的八个点及启用状态。每个风扇均可独立保存到草稿；页面保存时也会包含正在编辑的风扇。原始 PWM 字节（例如 254）在未编辑对应百分比时保留。

4. 点击「保存六套配置」，保存六套功耗和风扇草稿。切换编辑对象会保留草稿，但退出前必须保存。
5. 勾选并保存「自动联动功耗与风扇」，即可随实际运行方式和供电变化应用。立即测试可点击「应用当前草稿」，要求实际运行方式、供电和选中的组合一致。

未勾选的功耗项保留当前值；不接管风扇时保留现有设置。首次启用 asusd 功耗组时，服务可能加载其已有的组配置，本软件随后恢复未选中的功耗项。接入外接显卡、USB4 GPU Manager 开启自动显卡管理（或运行中但读取不到开关状态）、机身 NVIDIA 独显休眠或绑定到其他驱动时，跳过独显功耗项。CPU 功耗和机身风扇仍按组合设置，保存的独显参数会保留。实时监控跳过外接显卡传感器。

## EPP 联动

在「性能与散热 → 模式联动」配置 asusd 的静音、均衡、性能三档规则。插电和离电共享同一套规则，点击「保存 EPP 规则」独立保存到 asusd，退出本应用后仍生效。「保存六套配置」只保存功耗与风扇。旧的数值 EPP 字段在读取组合时忽略，再次保存时移除。

同一分区也提供本应用的供电自动切换和 asusd 插拔电源规则；前者更改后自动保存且只在应用运行时生效，后者点击「保存供电规则」保存到 asusd。启用任一 asusd 供电规则后，会关闭本应用的供电自动切换。

## 应用与失败处理

所有硬件调用在现有工作线程执行；每次应用前先检查完整配置、当前模式与供电、功耗范围、风扇能力。依次对功耗和风扇写入，并检查最终读数。部分失败时尝试恢复原来的功耗、风扇和功耗组开关，恢复失败会明确报错。应用期间切换供电或模式时中止，不把旧组合的参数恢复到新组合上。

组合配置存放在现有 `settings.json` 的 `combinations` 下，包含 `enabled`，及 `entries.<quiet|balanced|performance>.<ac|battery>`。每套独立保存 `power` 和 `fans`。普通供电策略的保存也会保留这些数据。联动默认关闭。没有保存组合配置时，检测到 ProArt P16 搭配 Ryzen AI 9 HX 370 会预填六套功耗和三路风扇曲线。启用联动后开始应用。其他机型的组合保持为空，由 asusctl/asusd 管理功耗和风扇。已保存的组合优先。

联动在程序运行期间持续采样，包括收进托盘后。通过托盘退出程序或停用联动后停止切换组合，已经应用的硬件／asusd 设置继续保留。asusd 的风扇曲线接口只按运行模式存储，插电／离电两套曲线由本软件保存并在切换时分别提交，因此退出程序后停止六套联动。

本机已只读确认三种模式、三路风扇、功耗接口及 asusd EPP 接口。自动化测试使用临时 sysfs 与模拟 D-Bus，验证六套隔离、旧配置兼容、回读、部分失败恢复、拔电中止、独显排队、草稿编辑及配置保留；没有为测试修改真实功耗、风扇或 EPP。
